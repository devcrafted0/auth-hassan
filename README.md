# 🛡️ create-auth-hassan

A specialized CLI tool designed to inject a production-ready **Authentication System** into your Next.js projects instantly.

Stop configuring providers, setting up database connections, and building authentication forms from scratch—just run a single command and get a fully functional `/auth` directory with everything pre-configured.

---

# 🚀 Tech Stack

This CLI is optimized for modern **Next.js App Router** development.

- **Framework:** Next.js 14+
- **UI Components:** shadcn/ui
- **Database:** MongoDB
- **Authentication Logic:** React Server Actions
- **Security:** Middleware-based route protection
---

# 📦 Installation

Install the package inside your Next.js project.

```bash
npm install create-auth-hassan
```

---

# 💻 Usage

Run the CLI in the **root directory of your Next.js project**.

```bash
npx create-auth-hassan
```

### What Happens?

The CLI automatically:

* Detects your Next.js project
* Generates a fully configured **`/auth` directory**
* Copies authentication components, logic, and configuration

You instantly get a working authentication system.

---

# 📂 Generated Project Structure

```text
.
├── app/
├── auth/                  # Generated by create-auth-hassan
│   ├── components/        # Login / Register / Reset UI
│   ├── lib/               # DB connection & Auth config
│   ├── actions/           # Server Actions (Auth logic)
│   ├── constants/         # Schemas, routes, helpers
│   └── middleware.ts      # Route protection
├── public/
├── tailwind.config.js
└── next.config.mjs
```

# 📋 Prerequisites

Before running the CLI, make sure your project has:

### 1️⃣ shadcn/ui initialized

```bash
npx shadcn-ui@latest init
```

### 2️⃣ Required shadcn components installed

```bash
npx shadcn-ui@latest add button input card label form
```

### 3️⃣ MongoDB connection ready

You should already have a MongoDB database URI.

---

# ⚙️ Environment Variables

After generating the files, create a **`.env.local`** file and add:

```env
MONGODB_URI=your_mongodb_connection_string
AUTH_SECRET=your_random_secret_key
NEXT_PUBLIC_APP_URL=http://localhost:3000
```

---

# 🔐 Authentication Flow

The generated system includes:

1. **Register**

   * Creates a new user
   * Hashes password securely

2. **Login**

   * Validates credentials
   * Creates secure session

3. **Middleware Protection**

   * Prevents unauthorized access
   * Protects private routes

4. **Server Actions**

   * Handles authentication logic securely on the server
